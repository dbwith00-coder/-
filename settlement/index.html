계산 기준

비우면 첫 기성 월부터

· 손익은 정산월(기성월)의 공급가액으로 잡습니다. 직불(인건비) 차감분은 기성 진행률·계약 잔액에는 넣고, 우리 통장을 거치지 않으므로 손익·현금흐름에서는 뺍니다.
· 기성 시트의 세금계산서 표 오른쪽(비고 다음)에 입금일·입금액 열(도급은 지급일·지급액)을 추가하면 추정 대신 실제 입금으로 미수금을 계산합니다.
· 고정지출 마스터는 매월 반복되는 것으로 보고 "당월 최종금액"을 매달 적용합니다. 급여는 지정일이 주말이면 직전 금요일로 옮깁니다.

구글 스프레드시트 실시간 연결 (Apps Script)

  1. script.google.com 에서 새 프로젝트를 만듭니다.
  2. Code.gs 에 저장소의 settlement/apps-script/Code.gs 내용을 붙여넣고, 맨 위 SPREADSHEET_IDS 에 시트 ID를 넣습니다.
  3. 파일 추가(+) → HTML → 이름을 Index 로 만들고 settlement/index.html 내용을 그대로 붙여넣습니다.
  4. 배포 → 새 배포 → 유형 웹 앱 · 실행 사용자 나 · 액세스 나만 (또는 조직 내 사용자)로 배포하고 나온 주소를 즐겨찾기합니다.

시트는 공개하지 않은 채로 두면 됩니다. 시트를 고치면 이 화면이 설정한 주기마다, 그리고 창으로 돌아올 때마다 다시 읽어 옵니다.

엑셀 파일로 보기

구글 시트에서 파일 → 다운로드 → Microsoft Excel(.xlsx)로 받은 파일을 넣으면 바로 볼 수 있습니다. 파일은 이 브라우저 안에서만 읽고, 자동 업데이트는 되지 않습니다.
