# 현장 손익·정산 관리

구글 스프레드시트(기성관리 시트, 고정지출 마스터)를 읽어서 아래 화면을 자동으로 만드는 내부용 대시보드입니다.
시트를 고치면 화면도 자동으로 다시 계산됩니다.

| 화면 | 내용 |
|---|---|
| 손익·현금흐름 | 월별 / 분기별 / 반기별 / 연도별 손익(공급가 기준)과 현금흐름(VAT 포함), 현장별 필터 |
| 현장 채권·채무 | 현장별 원청(받을 돈·미수금)과 도급업체(줄 돈·미지급금), 계산서 건별 미수·미지급 목록 |
| 기성관리 | 원본 기성관리 파일 양식 그대로 + 입금·미수 계산 열 |
| 월간 캘린더 | 고정지출(급여 주말 전진 배치 포함), 원청 입금·도급 지급 예정, 계산서 발행·직불 일정 |
| 데이터 연결 | 시트 인식 결과, 원청/도급 지정, 결제조건 등 계산 기준 |

## 연결 (Google Apps Script — 시트를 공개하지 않아도 됨)

1. [script.google.com](https://script.google.com/home/projects/create) 에서 새 프로젝트 생성
2. `Code.gs` ← [`apps-script/Code.gs`](apps-script/Code.gs) 붙여넣기, `SPREADSHEET_IDS` 에 시트 ID 입력
3. HTML 파일 `Index` 추가 ← [`index.html`](index.html) 붙여넣기
4. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 나만 또는 조직 내 사용자) → 나온 주소 사용

`index.html` 을 그냥 브라우저로 열면 엑셀 파일(.xlsx)을 넣어서 보거나 샘플 데이터로 둘러볼 수 있습니다 (자동 업데이트 없음).

## 시트 인식 규칙

- **기성관리 시트**: 위쪽에 `현장명` · `거래처` 칸, `계약내역` 행, 그리고 `정산일자 | 세금계산서 일자 | 공급가액 | 부가세 | 합계 | 비고` 표.
  - 표 제목에 `직불`·`차감` 이 있으면 직불 차감 표로 봅니다 (진행률·잔액에는 포함, 손익·현금흐름에서는 제외).
  - 시트 이름에 `매입`·`도급`·`외주` 가 있으면 도급업체(줄 돈), 아니면 원청(받을 돈). 데이터 연결 화면에서 바꿀 수 있습니다.
  - 표 오른쪽에 `입금일`·`입금액` (도급은 `지급일`·`지급액`) 열을 추가하면 실제 입금 기준으로 미수금을 계산합니다.
    열이 없으면 결제조건(기본 30일)이 지나면 정산된 것으로 **추정**하고 화면에 표시합니다.
- **고정지출 마스터**: `결제일 | 지출 내역 | 결제 방법 | 고정금액 | 외화 | 변동금액 | 당월 최종금액 | 결제구분` 헤더.
  매달 반복 적용하며, `급여` 는 지정일이 주말이면 직전 금요일로 옮깁니다.
